**Universal rules:**
- One UTM per creative (Appendix C scheme): e.g. `utm_campaign=bridal_launch&utm_content=adset_bridal_v1`
- Rotate creative weekly; kill worst performer, duplicate best (3 ad sets → 6)
- Never run prospecting without retargeting live behind it
- All copy above is DRAFT — A/B test headlines 1 vs 3 in week 1 and keep the winner
